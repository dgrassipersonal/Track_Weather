# Race Weather

Phone-first drag-racing weather dashboard for exact track locations.

## Tracks
1. South Mountain Raceway (default)
2. Beaver Springs Dragway
3. Maple Grove Raceway
4. Cecil County Dragway
5. Numidia Dragway

## V1
- GitHub Pages compatible static PWA
- NWS hourly point forecast
- Open-Meteo multi-model forecast
- GO / CAUTION / NO-GO racing-weather heuristic
- Rain probability and accumulation
- Track-drying index
- Wind and gusts
- Density altitude
- Hourly 7 AM–7 PM race window

## Run locally
Open `index.html` through any simple local web server.

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, select `main`, and use `/ (root)`.
